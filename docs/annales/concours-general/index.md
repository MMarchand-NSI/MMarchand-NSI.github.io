# Concours général de NSI

Le concours général des lycées comporte une épreuve de numérique et sciences informatiques, ouverte aux élèves de terminale suivant la spécialité. L'épreuve dure 5 heures, sans calculatrice. Les sujets sont longs, et leurs parties sont en grande partie indépendantes.

Chaque page reprend le sujet en entier. Le PDF original reste téléchargeable en tête de page.

| Session | Thèmes |
|---------|--------|
| [2026](cg-2026.md) | Robots et portails téléporteurs (structures de données, tests), algorithmes pour la compilation (allocation de registres, coloriage de graphes, forme SSA) |
| [2025](cg-2025.md) | Solveur SAT (logique booléenne, retour sur trace, SQL, sudoku), mélange de wagons (piles, files, plus long sous-train décroissant) |
| [2024](cg-2024.md) | Résistance des œufs (dichotomie, programmation dynamique), données en trois dimensions (voxels, graphes, maillages, demi-arêtes, SQL) |
| [2023](cg-2023.md) | Dans les coulisses du Web : polices et cliques, moteur CSS sur l'arbre DOM, protocoles de hachage cryptographique |
| [2022](cg-2022.md) | Structures de données d'un éditeur de texte, requêtes SQL sur un relief, découpage d'une grille par segments |
