# Concours Geipi Polytech : NSI

L'épreuve écrite du concours Geipi Polytech dure 3 heures : des mathématiques, puis une spécialité (2021, 2022) ou deux spécialités au choix (depuis 2023), parmi lesquelles la NSI. Le livret conseille d'y consacrer une heure par spécialité.

Les sujets sont surtout des **codes à compléter** : les réponses s'écrivent dans les cadres d'un document réponses, dont les éléments utiles sont reproduits sous chaque question. Chaque page donne aussi le PDF du sujet NSI avec son document réponses, et un lien vers le corrigé officiel publié par le concours.

| Session | Thèmes |
|---------|--------|
| [2026](geipi-2026.md) | Bataille navale : tuples, dictionnaires, dénombrement des placements, tir aléatoire pondéré |
| [2025](geipi-2025.md) | Chasse au trésor sur plateau carré ou hexagonal : dictionnaires, distances, graphe de visibilité, SQL |
| [2024](geipi-2024.md) | Composition nutritionnelle (SQL, dictionnaires), sentiers olympiques (graphes, Dijkstra) |
| [2023](geipi-2023.md) | Réseau de transports (dictionnaires), images dupliquées (similarité cosinus, glouton, cache) |
| [2022](geipi-2022.md) | IA pour un jeu à deux joueurs (récursivité), affectations sportives (parité, mariages stables) |
| [2021](geipi-2021.md) | Files et tourniquet, SQL et dichotomie, tas |

Source : [annales officielles du concours Geipi Polytech](https://www.geipi-polytech.org/annales-du-concours-geipi-polytech/).
